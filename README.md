# fastdemo — portfolios

Hub + portfolio styles. Add a new style as a folder (e.g. `/minimal/`), link it from the hub `index.html`.

| path | what |
| ---- | ---- |
| `/` | hub — plain list of styles |
| `/cool/` | three.js hero, terminal, persona demo |

## local preview

```bash
python3 -m http.server 8000
# hub  → http://localhost:8000/
# cool → http://localhost:8000/cool/
```
